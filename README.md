## Project Overview

QuickChat is a Java-based messaging application developed as part of my PROG5112 programming assignment.

The application demonstrates the use of Object-Oriented Programming (OOP), methods, classes, objects, decision-making structures, loops, arrays, string manipulation, validation, unit testing and JSON file storage.

The project was developed using Java in Apache NetBeans and was completed progressively through Part 1, Part 2 and the final Part 3/PoE.

---

## Project Goals

The main goals of the QuickChat application are:

- Create a functional messaging application using Java.
- Demonstrate Object-Oriented Programming principles.
- Create and use classes and objects.
- Implement methods to perform specific tasks.
- Validate usernames, passwords and cellphone numbers.
- Use decision-making structures.
- Use loops to process multiple messages.
- Store messages using arrays.
- Generate Message IDs.
- Generate Message Hashes.
- Send, disregard and store messages.
- Search for stored messages.
- Delete stored messages.
- Generate a message report.
- Store message information using JSON.
- Test the application using JUnit.
